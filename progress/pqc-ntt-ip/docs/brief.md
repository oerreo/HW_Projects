# Brief: pqc-ntt-ip

## 왜 이 주제인가
- **산업 수요**: FIPS 203/204가 2024년 8월 확정된 뒤 PQC는 SoC root-of-trust, 보안 IP의 필수 항목이 되었다. 팹리스 IP 엔지니어 포지션과 직접 맞닿는다.
- **수학적 깊이**: 유한체 산술, NTT(negacyclic convolution), 모듈러 reduction 알고리즘의 정확성 증명. 입력 공간이 작아 exhaustive 검증으로 "증명 수준"의 결과를 낼 수 있다.
- **HLS/RTL 분담이 자연스럽다**: 데이터패스(butterfly, reduction)는 HLS 탐색에 적합하고, 스케줄과 메모리 접근은 RTL 컨트롤러가 품질을 결정한다. 두 방식의 QoR 비교가 그대로 연구 결과가 된다.
- **자원 적합**: Zybo Z7-20(53K LUT, 220 DSP, 140 BRAM)에 여유 있게 들어가고, 시뮬레이션이 가벼워 공용 서버 제한(병렬 2) 안에서 진행 가능하다.
- **검증 가능성**: 표준 문서와 공인 테스트 벡터가 있어 golden이 명확하다.
- **본업과 분리**: 회사 업무(비디오 코덱)와 겹치지 않아 IP 분리가 깔끔하고, 포트폴리오의 폭을 넓힌다.

## 범위
- 포함: ML-KEM 다항식 연산 IP, RTL/HLS 이중 구현, AXI wrapper, FPGA 데모, ASIC 합성 수치
- 제외(초기): side-channel 대응(masking), 전체 KEM 프로토콜. 서베이 후 P4에서 재검토

## 예상 산출물
- 공개 가능한 IP 저장소(검증 환경 포함), 기술 문서, 논문 원고 1편
