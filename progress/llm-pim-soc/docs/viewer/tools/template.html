System Op Player

llm-pim-soc 시스템 RTL 시뮬레이션에서 드라이버가 낸 IP op와 ARM kernel 호출을 token 하나 동안 순서대로 재생한다.

시스템 구조와 현재 step

굵은 파란 테두리: 현재 step의 IP(또는 ARM). 굵은 선: 이번 op에서 beat가 오간 HP 포트와 GP0 경로. 점선: 이 빌드에 없는 slot 또는 tie-off 포트. 구조 원본: docs/spec/system.md 1.3, docs/diagrams/l4_sys_top.md.

현재 step

    token 타임라인

    가로축:

    막대 길이 = op의 CYCLES 레지스터 값. ARM step은 시뮬레이션 시간이 0이라 회색 세로선으로만 표시한다. 막대를 누르면 그 step으로 이동한다. 기호: G GEMV, C cls GEMV, A ATTN, W KVW, R RMSNORM, Q ACTQ, S SWIGLU, M ARGMAX, ARM ARM kernel.

    kernel 종류별 CYCLES (이 token)

    kernelop 수 (현재까지 / token)CYCLES 현재까지CYCLES tokentoken 비율RD_STALLWR_STALL

    op 수와 CYCLES는 실행기의 KSPLIT 분류(pim RUN은 첫 MACAB의 행렬, KVW는 attn)를 따른다. 합계, 누적, 비율은 생성 스크립트가 trace 값을 더해 넣은 값이다. 현재 step의 kernel 행이 강조된다.
