# 머신·툴 사용 제한

공용 서버다. 아래는 예외 없이 지킨다.

- **병렬도 최대 2**: 시뮬레이션, Catapult, 컴파일, agent를 합쳐 무거운 프로세스는 동시에 2개까지. `make -j`는 `-j2` 이하. 회귀 테스트는 순차 또는 2개씩.
- **Vivado 합성/구현 금지**: 이 머신에서 `vivado`를 실행하지 않는다. FPGA 작업은 Tcl/XDC/소스를 준비하고 사용자가 자기 환경에서 돌린다. 결과 리포트는 사용자가 전달해주면 분석한다.
- **DC는 허락받은 시점에만**: `dc_shell` 실행 전 반드시 사용자에게 무엇을(대상 모듈, 예상 시간) 돌릴지 알리고 승인을 받는다. 이전 승인은 다음 실행에 이어지지 않는다. 스크립트 작성은 자유.
- Catapult 내부에서 downstream 합성(DC/Vivado 호출)을 켜지 않는다. Catapult 자체 리포트까지만 사용한다.
- 긴 작업(수 분 이상)은 background로 돌리고, 끝나면 로그를 확인한다. 걸려 있는 프로세스는 남기지 않는다.
- 시뮬레이션 산출물(work 라이브러리, wave, 로그)은 `sim/` 아래에 두고 커밋 대상에서 제외한다. 대용량 wave dump는 디버그할 때만 켠다.
